Page 1 — API Tester

Test different API endpoints to see how RBAC controls access based on user roles and permissions. Each endpoint can return 200 OK (valid token + correct role), 401 Unauthorized (no/invalid token), or 403 Forbidden (valid token but insufficient role).

Endpoint 1: Public Access
Required Role: None (Public)

Description: This is a public endpoint that requires no authentication. Anyone can access this endpoint without a token.

Endpoint 2: Authenticated User
Required Role: Any Authenticated User

Description: This endpoint requires a valid authentication token. Any logged-in user can access this endpoint regardless of their role.

Endpoint 3: Admin Only
Required Role: admin

Description: This endpoint is restricted to users with the admin role only. Other roles will receive a 403 Forbidden response.

Endpoint 4: Clinician Only
Required Role: clinician

Description: This endpoint is restricted to users with the clinician role. Admin role also has access. Other roles will receive 403 Forbidden.

Endpoint 5: Receptionist Only
Required Role: receptionist

Description: This endpoint is restricted to users with the receptionist role. Admin role also has access. Other roles will receive 403 Forbidden.

Endpoint 6: Nurse Only
Required Role: nurse

Description: This endpoint is restricted to users with the nurse role. Admin role also has access. Other roles will receive 403 Forbidden.

Endpoint 7: Multi-Role Access
Required Role: admin, clinician, or nurse

Description: This endpoint allows access to multiple roles: admin, clinician, or nurse. Users with other roles will receive 403 Forbidden.
